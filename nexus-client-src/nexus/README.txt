NEXUS CLIENT (Fabric 1.21.4)
1. Wygeneruj szablon na https://fabricmc.net/develop/template/ (MC 1.21.4, Yarn, Java 21) - dzieki temu masz gradle wrapper.
2. Podmien w nim: build.gradle, gradle.properties, settings.gradle oraz caly folder src/ z tego projektu.
3. ./gradlew build  ->  build/libs/nexus-client-1.0.0.jar do folderu mods (razem z Fabric API).
4. W grze: RIGHT SHIFT otwiera GUI (klawisz zmienisz w Sterowaniu).
